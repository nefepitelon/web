## Display correction in 1.6.4

The 128px PNG canvas includes transparent padding around the original public logo (commonly 50px). `lib/cex-hub-icon-layouts.ts` records measured nontransparent bounds for every local logo. A centered CSS transform removes that canvas padding at display time; the image bytes, aspect ratio, and brand artwork remain unchanged. Directory frames are 40px and ranking frames are 30px, with a small visual inset. The correction applies only to mapped local images; remote fallbacks retain their normal sizing.
