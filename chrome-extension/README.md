# welinkBTC AI 运营发布助手

## 安装

1. 从 AI 运营台下载 `chrome-extension.zip` 并解压。
2. 在 Chrome 打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 `chrome-extension` 文件夹。
5. 固定工具栏里的“welinkBTC AI 运营发布助手”，点击图标可查看连接状态。

## 使用

1. 用同一 Chrome 配置登录微博、X 或币安。
2. 打开 AI 运营台，确认顶部显示“Chrome 桥接 · 已连接”。
3. 审核并保存草稿，勾选“我已确认平台登录”。
4. 点击“填充到…发布框”，助手会通过一次操作打开并等待平台编辑页就绪，再填入逐行文字和最多 3 张图片。
5. 确认无误后，由你亲自点击平台的发送按钮。

X 平台会先完成图片加载，再通过 X 自身的编辑事件逐字符、逐段提交正文。只有 X 确认内部正文状态与预览一致时，运营台才会提示填充成功。

## 安全边界

扩展只会把经过人工审核的文字和图片填入编辑框。它不会查找或点击任何发送、发布或 Post 按钮。
扩展不会读取密码、不会导出 Cookie、不会采集浏览历史，也不会把草稿发送到第三方内容服务。

## 权限说明

- 不申请 `tabs`、`clipboardRead`、`cookies`、`history`、`downloads`、`nativeMessaging` 或文件系统权限。
- 仅获准在 AI 运营台、微博、X 和币安广场这些明确列出的站点运行。
- AI 运营台权限用于接收用户主动点击“填充”时提交的草稿；平台权限只用于定位编辑框、填入文字和上传图片。
- 所有处理都在本机浏览器内完成，不包含分析统计、广告、远程脚本或后台数据上传。
