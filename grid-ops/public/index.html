Decibel · AptosPAPER 模拟
切换 live 前必须填写 API Key、API 钱包私钥和 Trading Account 地址。
实盘模式：API 密钥获取与配置

需要 3 项：DECIBEL_API_KEY、DECIBEL_PRIVATE_KEY、DECIBEL_SUBACCOUNT

  1. 获取 API Key：打开 geomi.dev（Aptos API 网关），注册账户并创建项目，然后生成 API Key，填入上方 API Key。
  2. 创建 API 钱包：打开 Decibel API 页面，连接钱包并创建 API Wallet。复制生成的 Ed25519 私钥，填入“API 钱包私钥”。
  3. 填写交易账户：在 Decibel 交易界面找到 Trading Account（子账户）地址，复制以 0x 开头的地址，填入“Trading Account 地址”。
  4. 充入 APT 手续费：将 APT 转入 Decibel API 页显示的 API Wallet Address，不是 Trading Account。启动时系统会按当前 gas 价格检查最低预留；每次挂单、撤单和设置杠杆都是 Aptos 链上交易。
  5. 检查保证金：确认 Trading Account 已有足够的 USDC 作为交易保证金，再切换到 live 实盘。APT 与 USDC 用途不同，两者都需要。
⚠ 这里只能填写专用 API 钱包私钥。不要填写主钱包助记词或主钱包私钥；密钥仅保存在本机 .env 文件中。API Wallet 保留 APT 支付 gas，Trading Account 保留 USDC 作为保证金。
Extended · StarknetPAPER 模拟
切换 live 前必须填写 API Key、Vault ID、Stark 私钥和公钥。
实盘模式：API 密钥获取与配置

需要 4 项：EXTENDED_API_KEY、EXTENDED_VAULT、EXTENDED_STARK_PRIVATE_KEY、EXTENDED_STARK_PUBLIC_KEY

  1. 开通交易账户：打开 app.extended.exchange，连接钱包并按页面提示完成开户。
  2. 创建 API Key：进入账户设置或头像菜单中的 API Management，选择 Create API Key。
  3. 立即保存 4 个值：复制 API Key、Vault（数字 ID）、Stark Private Key 和 Stark Public Key，分别填入上方对应字段。
  4. 检查费率与资金：机器人会从 /api/v1/user/fees 自动读取该子账户、该市场当前的 maker/taker 费率；EXTENDED_MAX_FEE 只是安全上限，建议保持默认 0.0005。
  5. 启动前确认：账户需有足够的 USDC 保证金；费率变更导致 1128 明确拒单时，机器人会刷新费率并重新签名安全重试一次。
⚠ Stark 私钥通常只显示一次，请创建后立即安全保存。不要截图或发送给他人；密钥仅保存在本机 .env 文件中。
RISExPAPER 模拟
切换 live 前必须填写账户地址和签名私钥。
实盘模式：API 密钥获取与配置

需要 2 项：ACCOUNT_ADDRESS、SIGNER_PRIVATE_KEY

  1. 开通交易账户：打开 RISEx 官方交易应用，连接钱包并完成开户。
  2. 获取签名凭据：进入账户、API 或安全设置，复制账户地址，并按 RISEx 官方说明创建或导出用于签名下单的 Signer 私钥。
  3. 对应填写：将地址填入“账户地址”，将 Signer 私钥填入“签名私钥”；确认账户已有足够保证金，再切换到 live 实盘。
  4. 使用官方节点：RISEX_API_URL 和 RISEX_WS_URL 一般保持为空，系统会使用官方默认地址。
⚠ 仅使用 RISEx 下单所需的 Signer 私钥，不要填写主钱包助记词；密钥仅保存在本机 .env 文件中。

代理服务商提供 HTTP 节点时应填写 http://；它仍可通过 CONNECT 安全访问 HTTPS 交易接口，不要自行改成 https://。

🌐 全局代理（GLOBAL_PROXY）

最低优先级的统一兜底通道。控制台始终优先启动；全局通道检测失败只会显示告警，不会阻止进入本页。网络不可达的 LIVE 交易所会保持离线并禁止启动网格，修复后可立即检测并重连。留空或填写 direct 表示全局通道使用本机直连。

⬡ Decibel 独立代理（DECIBEL_PROXY）

仅用于 Decibel；本机直连失败后尝试，仍失败才使用全局代理。支持 HTTP(S) 和 SOCKS5。

⬡ Extended 独立代理（EXTENDED_PROXY）

仅用于 Extended；本机直连失败后尝试，仍失败才使用全局代理。

⬡ RISEx 独立代理（RISEX_PROXY）

仅用于 RISEx；本机直连失败后尝试，仍失败才使用全局代理。

🔍 网络调用链诊断

逐项按“直连 → 独立代理 → 全局代理”检测并自动应用首个可用通道；展示每次尝试和最终路线，不会回传 API Key、私钥或代理密码。

⚠ 新保存的代理会立即应用；正在执行的旧请求不受影响，后续请求走新路由。
自动修复只切换网络路线；查询类请求可以重新检测，下单请求绝不会跨路线盲目重放，避免重复订单。
LIVE 模式切换网络前请先确认地区合规与交易所访问要求。
