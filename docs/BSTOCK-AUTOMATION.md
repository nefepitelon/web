# bStockAlpha 自动交易

## 使用边界

- 板块位于「组合与 Realized PnL」上方，初始关闭。首次开启须明确确认预算和真实买卖授权。
- Agentic Wallet 扫码会话支持后台执行；普通浏览器钱包仍逐笔签名，不开放无人值守执行。连接方式及账户相互隔离。同一地址自动交易运行或订单待核对时，本平台手动下单会被阻止。
- 开启后关闭页面不会停止；手动关闭开关停止后续新单，不清仓。已占用提交资格或已广播订单继续核对。授权最长 24 小时，且不超过原钱包会话期限。
- 仅交易官方 bStock 现货，执行链为 BNB Smart Chain。不会改动 x402 多链付款功能，不会自动购买新的付费研报、不转出资金、不使用杠杆或亏损翻倍加仓。
- 盈利、胜率与翻倍时间不作承诺。历史研究不等于本策略在 bStock 上的实盘验证。止损是后台定时检查，不是交易所保证单；行情、网络或流动性异常可能导致无法及时卖出。

## 策略与风控

`bstock-auto-20260908-v1` 使用最近已收盘的 1 小时数据。至少 35 根连续有效K线；最新收盘超过75分钟或行情快照超过120秒时不新开仓。

- 趋势：EMA10/EMA30 上行过滤和收盘突破，拒绝追涨超过止损幅度。
- 均值回归：20周期、2倍标准差布林带，在平缓趋势中等待下轨收复与反弹确认；回归入场记录中轨、止盈、止损或移动止损时退出。
- 自适应只按行情条件选择上述规则，评分不是胜率。
- 入场必须已有当前钱包7天内的成功 Agent Studio 研报；复用 CMC、确定性评分、官方资产、真实余额与 Gas 复核。
- 默认预算 $100，单笔 $20，最多3个仓位；默认止损3%、止盈6%、回撤10%、日亏5%、扫描60秒。单笔不超过预算25%；止盈至少为止损1.5倍。
- 自动开仓后的单标的总敞口严格低于钱包25%；单笔不超过$500/预算25%，总预算最高$2,000，每日买入周转不超过预算2倍。
- 报价需通过价格偏差及往返费用检查。策略风险净值计入 Gas；展示的策略已实现 PnL 依原口径不含 Gas。
- 触及回撤/日亏限额后锁定只退出模式，尝试分批卖出机器人持仓后暂停。恢复行情不会重新买入；需用户显式重新启动。

参考仅用于规则设计：

- [AQR：Time Series Momentum](https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum) 是长期动量研究，不是本小时级策略的复现或收益背书。
- [Fidelity：Bollinger Bands](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/bollinger-bands) 提供指标说明，非高胜率保证。

## 执行与审计

后台使用 Workflow 持久任务，周期性重新读取授权；钱包会话仅以现有服务器加密方式保存，接口与导出不返回会话。数据库四张自动交易表启用 RLS 并撤销浏览器角色权限。

每个运行批次、策略版本、筛选指标、研报ID、报价、风控原因、订单号、交易哈希、实际资金流、费用和持仓成本都有记录。事件导出支持完整分页；订单列表导出最近1,000笔，历史事件保留订单证据。

同一钱包使用事务锁、执行租约、单个在途订单限制、唯一信号键及意图原子占用。网络重试不重新广播订单。成交必须匹配钱包、代币、方向、金额和链上两次区块确认，才入机器人账本。

## 异常处理

- 开启前会按当前已验证的钱包身份核对历史手动订单；重新扫码不再仅依赖旧登录会话的 `agentKey`。历史 `SUBMITTED` 不会仅因年龄被清除：有精确订单证据、成功链上回执与确认数后才能同步终态，已失败/取消订单需上游明确终态。
- 「核对历史订单」只查询订单及链上证据、同步审计状态，不会开启机器人、签名或重放交易。核对有时间/数量上限，未完成时显示剩余订单，可再次核对；完成后仍需用户重新明确开启。详情区显示阻塞的标的、订单号、状态和报价等待时间。
- 「已核对忽略」和「全部忽略」是用户明确复核后的启动拦截豁免，不是撤单、成交确认或删除。二次确认后只写入原手动记录的 `automationIgnoredAt` / `automationIgnoredBy`，并在同一事务保存 `MANUAL_ORDERS_IGNORED` 审计事件（逐条原始快照、复核人、时间、范围与版本）；订单号、交易哈希、真实状态、持仓和 PnL 不改写。忽略并不代表交易未成交，仍须在钱包中核对实际结果。
- 批量忽略绑定当前完整快照，不仅是首屏10条；出现新订单或订单内容变化时返回409并要求重新复核，不自动重试。超过1,000条仅开放单条忽略。自动交易订单和有效手动报价不可忽略；报价保留原90秒保守窗口。
- 忽略后不自动开启机器人，须另行确认策略和预算。启动及最终广播在同一钱包锁下重新检查未忽略手动订单；余额、Gas、授权、预算等风控仍照常执行。旧的忽略标记不能被复用于新的浏览器交易哈希；已广播同一交易哈希的登记重试不会改变原记录。启动前的有界核对只处理未忽略记录，避免历史记录占满查询名额。
- 未忽略的提交中、状态未知或没有可验证证据的订单仍会阻止自动启动。所有核对在数据库锁外读取证据、锁内条件更新，避免与新的手动提交竞态。
- `PROCESSING` 及未识别的非终态同样保持拦截；相似金额、时间或用户提供的关联 ID 不作为结案证据。普通状态轮询只同步明确身份的待确认状态，手动订单终态由历史核对的证据验证流程同步，自动订单由独立成交回执校验器处理。
- `WAITING`：行情/RPC暂不可用，等待下一轮；不以缓存或演示数据代替。
- `UNKNOWN` / `PENDING`：不要重复提交。先查看 Agentic Wallet 订单与链上回执；历史手动单复核后可显式忽略其启动拦截，自动交易在途订单不可用此方式绕过。
- `RECONCILIATION_REQUIRED`：钱包持仓、合约或拆股倍率与策略账本不一致，暂停；不得直接清除账本重新启动。
- `EXPIRED` / `SESSION_INVALID`：重新扫码。若有未核对订单，先核对链上证据或明确复核历史手动记录，不可丢弃或重放旧订单。
- 手动停止与数据服务恢复不会自动清仓或重开。
