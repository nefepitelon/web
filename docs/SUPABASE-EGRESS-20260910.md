# Supabase Egress 复查（2026-09-10）

截图为账期累计 2.89 GB，9 月 9 日仍有新增。本次用生产查询统计与 Vercel 日志复核，不能将累计查询次数直接当作某一天的账单。

## 定位

- 对比约 24.76 小时前采样，旧托管网格后台整行读取、全行心跳返回均新增 0 次；按用户整行读取仅新增 102 次（窗口包含前次发布之前）。短窗口复采样未见旧网格热点继续增长。
- 当前热点转到 Alpha 交易中心。最近一小时日志中状态路径 480 条、自动交易路径 379 条；日志数不等于独立用户数或精确请求数。状态查询在长窗口新增 2348 次，每次读取 20 个完整计划、40 个完整订单、40 个持仓和 60 条完整审计记录。
- 约 102 秒复采样确认 Alpha 配置的空 update upsert 持续产生三组重复 SELECT。其鉴权与配置查询仍活跃。
- 箱体突破存在最高约 1.9 MB 的不可变结果快照。看板刷新重复读取整个快照；公共市场缓存写入还会返回刚写入的完整 JSON。

## 修复

1. 状态查询在数据库层排除订单原始响应、计划执行载荷和审计 metadata，仅读取界面用到的字段。审计导出和交易执行仍按原有完整路径读取。
2. 已有执行配置和自动交易配置直接读取；仅首次使用走原子 upsert。旧模式回退规则保留。
3. Alpha 展示在无活动订单和持仓时每 60 秒刷新；自动交易面板停止时每 60 秒刷新，运行/收尾保留 15 秒；隐藏标签页停止展示请求。交易指令仍实时校验，不缓存权限或交易决策。
4. 按用户和任务 ID 缓存不可变扫描结果，每实例最多 16 项、16 MiB、10 分钟，合并并发读取。结果克隆隔离调用者；缺失/失败不缓存。动态扫描进度、设置、权限每次仍读取；新扫描使用新任务键。
5. 审计写入和无需返回结果的快照写入只返回主键，避免回传整个 JSON。

## 验证

生产只读验证覆盖 23 个当前 PAPER/LIVE 配置账户。新旧展示字段一致，订单/计划/审计载荷合计从 194514 B 降到 81261 B，减少 58%。此比例只描述这些查询数据，不代表全组织账单降幅。诊断禁止数据库写入，跳过需迁移的历史旧模式。

缓存验证覆盖用户隔离、并发合并、调用者修改隔离、过期、容量淘汰、错误/缺失重试。配置验证覆盖已有配置只读、首次并发创建保留原子行为、旧模式回退。轮询验证覆盖空闲、活动订单、未知持仓和隐藏页面。
